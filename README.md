# YHKS-EnvSwitch

開発用サーバーの状態の切り替え(フォルダーの入れ替え、properties ファイルの書き換え、WebLogic のデータソースの書き換え)をまとめて行う Windows 用の道具です。サーバーが動いていれば、停止を指示してから切り替えます。サーバーの起動は Eclipse から手で行います。

共有サーバー側は読むだけで、変更しません。

## 1. 入れる

1. [Releases](https://github.com/nekosama-orz/YHKS-EnvSwitch/releases/latest) から `YHKS-EnvSwitch-win-Setup.exe` をダウンロードして実行する。
2. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押す(署名のない自作アプリのため)。
3. 入れ終わると、自動で起動します。スタートメニューとデスクトップにショートカットができます。

管理者の権限は要りません。タスクバーに置きたいときは、起動中のアイコンを右クリックして「タスクバーにピン留めする」を選びます。

## 2. 設定する

初めて起動すると、設定画面が開きます。あとから開くときは、メイン画面の「設定」を押します。

- 同じ環境の人から設定のファイルを受け取っているときは、「ファイルから読み込む」で読み込みます。そのあと、自分のPCに合わない項目を直します。直すことが多いのは、手元のコピー先、作業用フォルダー、properties ファイル、ドメインのフォルダー、wlst.cmd の場所、サーバーの名前、サーバーのポートです。「停止を指示する接続先」は、ふつう空にします。
- 場所は「参照」で選べます。変数名、サーバーの名前、データソースの名前などは、フォルダーやファイルから読んだ候補から選べます(候補が出ないときは、手で入力します)。
- 項目の名前に「(必須)」とあるものは、入力が必要です。「(任意)」は空のままでかまいません。
- 項目の下に、調べた結果が出ます。赤い文字は、直すところです。
- 「設定をテストして保存」を押すと、もう一度調べてから保存します。入力漏れ、書き方の誤り、場所の重なり、properties ファイルに同じ変数が2つあるなど、直すところがあるときは保存できません。場所やファイルが見つからないだけのとき(VPN につないでいないときなど)は、確かめたうえで保存できます。
- 自分の設定をほかの人に渡すときは、「ファイルに書き出す」を使います。書き出したファイルには、フォルダーの場所や名前が入っています。

「ドメインのフォルダー」は、必ず Eclipse の画面で確かめてください(Servers ビューでサーバーをダブルクリック → Domain Directory の欄)。別のドメインを書くと、道具は成功したように見えても、Eclipse から起動したサーバーには反映されません。

Eclipse の設定も1つ確かめてください。「ウィンドウ」→「設定」→「一般」→「ワークスペース」の「ネイティブ・フックまたはポーリングを使用してリフレッシュ」をオンにします。オフのままだと、道具が入れ替えたファイルに Eclipse がすぐ気づかず、サーバーを起動しても前の状態のファイルが使われることがあります(前の状態のアカウントでログインできてしまう、など)。

## 3. 切り替えのテスト(何も変更しない)

設定を保存したら、切り替える前に必ず行います。

1. 切り替えたい状態を一覧から選ぶ。
2. 「切り替えのテスト(何も変更しない)」を押す。WebLogic の確認に数十秒かかります。
3. 項目がすべて `[OK]` になれば準備完了です。

`[NG]` が出たら、その行の説明に従って設定を直します。「WebLogic の設定」が `[NG]` のときは、「WLST の出力を表示」を押すと、WebLogic の道具が出した内容を見られます。

サーバーを起動した状態でも一度行い、「停止の指示」の項目が `[OK]` になることを確かめてください(サーバーに接続して相手を確かめるだけで、止めません)。

## 4. 切り替える

初めての切り替えの前だけ、念のため次の2つを手で控えてください。

- ドメインのフォルダーの中の `config` フォルダー(コピーを別の場所に置く)
- properties ファイル(コピーを別の場所に置く)

手順:

1. 状態を選んで「切り替え」を押す。サーバーが動いているときは、ボタンが「サーバーを停止して切り替え」に変わり、道具がサーバーに停止を指示してから切り替えます。
2. 終わるまで待つ(コピーの時間 + 1分ほど)。
3. 「切り替えました。Eclipse でサーバーを起動してください」と出たら、Eclipse の Servers ビューでサーバーの表示が「再公開」になっていることを確かめて、起動する。「同期済み」のままなら、Eclipse が入れ替えに気づいていません。サーバーを右クリックして「Clean」を選んでから起動します。

気を付けること:

- 共有サーバーの状態のフォルダーを誰かが更新している間は、切り替えないでください。新しい中身と古い中身が混ざることがあります。更新が終わってから切り替えます。
- 停止は通常の停止です。処理が残っていて60秒たっても止まらないときは、WebLogic が強制的に止めます(デバッグでブレークポイントに止めたまま押したときなど)。
- 資格情報は、WebLogic がサーバーの `boot.properties` から読みます。道具はパスワードを扱いません。

初めてのときは、次も確かめてください。

- 手元のフォルダーの中身が、選んだ状態のものになっている
- properties ファイルの値が変わり、コメントの行は変わっていない
- Remote Console で、データソースのプロパティの値が変わっている
- システムが、選んだ状態で動く(データベースにつながる)
- 道具がサーバーを止めたあと、Eclipse の Servers ビューの表示が「停止」になり、Eclipse から普通に起動できる

## 5. うまくいかないとき

- 切り替えの途中で失敗したら、道具が変えた分を自動で元に戻します。画面の `[失敗]` の行に理由が出ます。
- 切り替えの途中で道具やPCが落ちたら、次に起動したときに「元に戻す」ボタンが出ます。サーバーを起動せずに押してください。元に戻すまで、設定の保存とアンインストールはできません。
- 入れ替える前の手元のフォルダー、properties ファイル、ドメインの `config` は、作業用フォルダーの `backup` フォルダーに1回分残ります。
- 「停止の指示」が `[NG]` のとき、または停止できなかったときは、フォルダーと設定は何も変わっていません。Eclipse でサーバーを停止すれば、「切り替え」で切り替えられます。
- 「サーバーが止まっていると判断できません」と出るのは、WebLogic の Java のプロセスが残っているときです。Eclipse で停止し、数秒待ってからやり直します。
- 「WebLogic が2個動いています」と出るときは、どれを止めるか道具が決められないので、Eclipse で停止してから切り替えます。
- 切り替えたのに、システムが前の状態のまま動く(前の状態のアカウントでログインできる、など)ときは、Eclipse が前の状態のファイルをサーバーに配ったままです。Servers ビューでサーバーを右クリックして「Clean」を選び、起動し直します。何度も起きるときは、「2. 設定する」の Eclipse の設定(ネイティブ・フックまたはポーリングを使用してリフレッシュ)がオンになっているか確かめます。
- 動きがおかしいときは、道具を閉じて開き直します。
- この説明は、メイン画面の右下の「使い方」を押すと、いつでもブラウザーで開けます。

困ったときは、「診断情報をコピー」で版とログ(操作と失敗の種類だけ。場所や値は入っていません)をコピーして、道具を配った人に伝えてください。画面の `[NG]` や `[失敗]` の行、「WLST の出力」には、フォルダーの場所や名前が入ることがあります。伝える前に読んで、伏せるところを伏せてください。

## 6. 更新

更新は自動です。起動したときと、その後24時間ごとに新しい版を確かめ、あれば、切り替えなどをしていないときに更新して起動し直します。すぐに更新したいときは、道具を閉じて開き直します。

## 7. 削除する

設定画面の左下の「アンインストール」を押すか、Windows の「設定」→「アプリ」→「インストールされているアプリ」から `YHKS-EnvSwitch` をアンインストールします。切り替えの途中と、「元に戻す」ボタンが出ている間は行わないでください(設定画面のボタンは押せなくなりますが、Windows の「アプリ」からは削除できてしまいます)。その状態で削除してしまったときは、もう一度入れると「元に戻す」を使えます。

次のものは残ります。要らなければ、手で消してください。

- 設定とログ: エクスプローラーのアドレスバーに `%APPDATA%\YHKS-EnvSwitch` と入れると開きます。
- 作業用フォルダー(設定で決めた場所。控えが入っています)。

手元のフォルダー、properties ファイル、WebLogic の設定は、アンインストールしても変わりません。

## 8. v0.2.0 以前(zip で配っていた版)から移る

1. 古い版を起動し、「元に戻す」ボタンが出ていないことを確かめて、閉じる(出ていたら、先に押す)。
2. この版を入れる(上の「1. 入れる」)。
3. 設定画面の「ファイルから読み込む」で、古い版のフォルダーにある `config.json` を選び、「設定をテストして保存」を押す。
4. 「切り替えのテスト(何も変更しない)」で確かめる。
5. 古い版のフォルダーを消す。古いログのフォルダー(`%LOCALAPPDATA%\EnvSwitch`)も消してかまいません。
